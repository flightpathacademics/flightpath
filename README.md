# FlightPath - Academic Advising and Student Success

FlightPath is an enterprise-level, web-based academic advising and student success platform.
See videos and screenshots at: https://flightpathacademics.com


## Professional hosting and support

FlightPath Academics offers professional hosting and support, as well as
exclusive features for FlightPath not found in this community edition.

Visit https://flightpathacademics.com for more information. 


## Minimum Requirements

FlightPath requires a web server (Linux recommended) configured with the following:

 * Apache 2.4+ or Nginx
 * MySQL/MariaDB
 * PHP 7.4+ (PHP 8.x recommended)
 * 2GB RAM 
	* PHP memory_limit at least 512M, 1024M recommended


To use FlightPath as an end-user, the following is required: 

 * Computer/tablet/phone capable of running a modern and updated web browser
	* eg, Chrome, Firefox, Edge, etc
	* JavaScript must be enabled
 * At least 4GB system memory for computers/laptops
